# Initial release

This repository was exported as a fresh source snapshot from the research project, without its Git history, manuscripts, peer-review material, data, checkpoints, logs, or credentials.

Included source files are listed by SHA-256 in `SOURCE_MANIFEST.json`. The Pixi workspace name and public documentation were adapted for this repository. The original research checkout remains separate.

After paper acceptance, planned additions include documented experiment configurations, eligible weights/data access instructions, gprMax comparison tooling, complete reproduction commands and final licensing/citation information. These items are planned, not currently supplied.

## Validation of this snapshot

The 242 included unit tests passed using the existing Linux Pixi environment. Training and evaluation CLI help completed successfully, and the documented CPU layered-data example generated four samples. A fresh environment installation and full paper-scale retraining were not performed for this initial export.
